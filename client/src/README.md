#ICSI 418Y Programming Assignment 3

For this assignment, I continued from my PA2 login and signup project and added the ability to create projects and memberships to the selected projects.The project uses React, Node.js, Express, and MongoDB Atlas.

##Features
The application allows users to:
Sign up for an account, log in, create a project, choose an already registered user as the project leader, choose a project progress status, view all projects, view the members of a project, add users to projects, remove members from projects, prevent duplicate memberships, and prevent the project leader from being removed.

##How to Run It:
The frontend and backend need to run at the same time.
